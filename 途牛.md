# 酒店

## 概述

途牛酒店服务提供酒店搜索、详情查询和在线预订功能，支持集成到 AI 助手、智能客服等应用中。

**核心特性**:

- 🚀 无状态设计，无需维护会话
- 🔐 基于 API Key 认证
- 💾 智能缓存，提升响应速度
- 📦 完整的预订流程（搜索→详情→下单）

## 一、Tools 列表

### 1.1 tuniuHotelSearch（酒店搜索）

功能: 根据城市、日期等条件搜索酒店，支持翻页。

#### 请求说明

| 参数        | 类型     | 必需   | 说明                                                         |
| :---------- | :------- | :----- | :----------------------------------------------------------- |
| `cityName`  | string   | ✅ 首页 | 城市名称（如"北京"），第一页必填                             |
| `checkIn`   | string   | ⚠️      | 入住日期 YYYY-MM-DD；与 `checkOut` 须同时传入或都不传；都不传时默认今天 |
| `checkOut`  | string   | ⚠️      | 离店日期 YYYY-MM-DD（默认明天）                              |
| `keyword`   | string   | ❌      | 搜索关键词（酒店名称等），多个用空格隔开                     |
| `poiName`   | string   | ❌      | POI 名称，按该地点约 4 公里范围内查酒店                      |
| `prices`    | string   | ❌      | 价格区间（如"300-800"）                                      |
| `adultNum`  | number   | ❌      | 成人数（默认2）                                              |
| `childNum`  | number   | ❌      | 儿童数（默认0）                                              |
| `childAges` | number[] | ❌      | 儿童年龄列表，数量与 `childNum` 一致                         |
| 翻页参数    |          |        |                                                              |
| `queryId`   | string   | ✅ 翻页 | 首次搜索返回的ID                                             |
| `pageNum`   | number   | ✅ 翻页 | 页码（从2开始）                                              |

> 翻页时只传 `queryId` + `pageNum`，无需再传城市等搜索条件。

#### 响应说明

| 参数             | 类型    | 说明                                             |
| :--------------- | :------ | :----------------------------------------------- |
| `displayHint`    | string  | 给模型的展示提示（表格列、价格格式、翻页说明等） |

### 1.3 tuniuHotelCreateOrder（创建订单）

功能: 创建酒店预订订单，系统会自动验价。

> 前置条件：⚠️ 必须先调用 `tuniuHotelDetail` 获取最新的 `preBookParam`

| 参数           | 类型   | 必需 | 说明                               |
| :------------- | :----- | :--- | :--------------------------------- |
| `hotelId`      | string | ✅    | 酒店ID（字符串）                   |

## 二、完整预订流程

### 2.1 流程图



```
搜索酒店 → 选择酒店 → 查看详情 → 选择房型 → 创建订单 → 支付
   ↓           ↓           ↓           ↓           ↓
queryId    hotelId   roomTypeId  preBookParam  orderId
                                 (有效期30分钟)
```

### 2.2 命令行示例

调用前请先阅读 [途牛 CLI 使用指南](https://open.tuniu.com/mcp/docs/apidoc/cli/usage.html)。

命令格式：



```
tuniu call <服务> <工具名> -a '<JSON 入参>'
```

本页示例使用：`tuniu call hotel <工具名称> -a '<JSON 入参>'`。

**参数来源**：`hotelId`、`roomId`、`preBookParam` 等须从搜索与详情接口返回中取值。

#### 步骤 1：搜索酒店



```
tuniu call hotel tuniuHotelSearch -a '{
  "cityName": "北京",
  "checkIn": "2026-03-01",
  "checkOut": "2026-03-03"
}'
```

翻页示例（使用搜索返回的 `queryId`）：



```
tuniu call hotel tuniuHotelSearch -a '{
  "queryId": "1317101481369856",
  "pageNum": 2
}'
```

#### 步骤 2：查看酒店详情



```
tuniu call hotel tuniuHotelDetail -a '{
  "hotelId": 12345,
  "checkIn": "2026-03-01",
  "checkOut": "2026-03-03"
}'
```

#### 步骤 3：创建订单（preBookParam 来自详情报价，有效期约 30 分钟）



```

  "hotelId": "12345",

  "preBookParam": "eyJ0eXAiOiJKV1Qi...",
  "checkInDate": "2026-03-01",
  "checkOutDate": "2026-03-03",
  "roomCount": 1,
  "roomGuests": [
    {
      "guests": [
        {
          "firstName": "三",
          "lastName": "张"
        }
      ]
    }
  ],

  "contactPhone": "13800138000"
```

# 机票

## 概述

途牛机票服务提供国内航班搜索、舱位查询和在线预订功能，支持集成到 AI 助手、智能客服等应用中。

**核心特性**:

- 🚀 无状态设计，无需维护会话
- 🔐 基于 API Key 认证
- 💾 智能缓存，提升响应速度
- 📦 完整的预订流程（搜索→舱位→下单）
- 支持 6 种查询模式（低价、时间范围、价格区间、周边出发、周边到达、中转）

## 一、Tools 列表

### 1.1 searchLowestPriceFlight（航班搜索）

功能：根据出发城市、到达城市和日期搜索航班，支持 6 种查询模式，支持分页查询。

#### 请求说明

查询模式说明：

| searchType | 说明                    | 额外参数                     |
| :--------- | :---------------------- | :--------------------------- |
| 不传/空    | 默认低价查询            | 无                           |
| TIME       | 按出发/到达时间范围查询 | departureTime 或 arrivalTime |
| PRICE      | 按价格区间查询          | priceRange                   |
| NEAR_GO    | 周边机场出发查询        | 无                           |
| NEAR_BACK  | 周边机场到达查询        | 无                           |
| TRANSFER   | 中转航班查询            | 无                           |

参数表：

| 参数                | 类型   | 必需 | 说明                                            |

# 门票

## 概述

途牛门票服务提供景点门票查询和在线预订功能，支持集成到 AI 助手、智能客服等应用中。

**核心特性**:

- 🚀 无状态设计，无需维护会话
- 🔐 基于 API Key 认证
- 💾 智能缓存，提升响应速度
- 📦 完整的预订流程（查询→下单）

## 一、Tools 列表

### 1.1 query_cheapest_tickets（门票查询）

功能：根据景点名称查询门票价格和票型信息。

#### 请求说明

| 参数          | 类型   | 必需 | 说明                                                         |
| :------------ | :----- | :--- | :----------------------------------------------------------- |
| `scenic_name` | string | ✅    | 景点名称（如"南京中山陵"）                                   |
| `depart_date` | string | ❌    | 出游日期，格式 `YYYY-MM-DD`。用户指定日期时应传入；传入后仅返回 `startDate`～`endDate` 覆盖该日期的可售门票 |

#### 响应说明

| 参数          | 类型   | 说明     |
| :------------ | :----- | :------- |
| `scenic_name` | string | 景点名称 |
| `tickets`     | array  | 门票列表 |

**tickets 数组元素**

| 参数             | 类型   | 说明                                                         |
| :--------------- | :----- | :----------------------------------------------------------- |
| `productId`      | number | ⚠️ 产品 ID（下单时使用）                                      |
| `resId`          | string | ⚠️ 资源 ID（下单时使用）                                      |
| `startPrice`     | string | 起价（元）。可售区间内的最低价，**不是**用户指定日期当天的真实价格 |
| `departsDate`    | string | 起价对应团期，可能与用户指定的 `depart_date` 不同            |
| `startDate`      | string | 最早可售日期                                                 |
| `endDate`        | string | 最晚可售日期                                                 |
| `ticketTypeName` | string | 票型名称                                                     |
| `resName`        | string | 资源 / 票种名称                                              |

**结果含义与展示约束**

- 传入 `depart_date` 时，列表中每张门票均满足 `startDate` ≤ 指定日期 ≤ `endDate`。
- `startPrice` 是起价，`departsDate` 是该起价对应团期，不能当作指定出游日的实价。
- 向用户展示价格时必须加「起」，例如 `¥50起`，禁止写成「指定日期 ¥50」。

#### 入参示例



```
{
  "scenic_name": "南京中山陵",
  "depart_date": "2026-04-01"
}
```

未指定出游日期时，可只传 `scenic_name`。

#### 响应示例



```
{
  "scenic_name": "南京中山陵",
  "tickets": [
    {
      "productId": 12345,
      "resId": "res001",
      "startPrice": "50",
      "departsDate": "2026-03-21",
      "startDate": "2026-03-21",
      "endDate": "2026-04-30",
      "ticketTypeName": "成人票",
      "resName": "中山陵成人票"
    }
  ]
}
```

上例中用户查询的是 `2026-04-01`，该票可售区间为 `2026-03-21`～`2026-04-30`（覆盖指定日期）；`startPrice=50`、`departsDate=2026-03-21` 表示起价及其对应团期，回复时应写成「¥50起」。

## 概述
