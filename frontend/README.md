# 前端模块导航

前端继续使用 HTML、CSS、JavaScript，不需要构建。所有脚本按 `index.html` 中的顺序延后加载，在页面完成解析后启动账户恢复；业务操作仍通过同一后端接口执行。

| 目录 | 职责 |
| --- | --- |
| `core/` | 账户恢复、共享界面状态、HTTP、任务与 SSE |
| `views/` | 消息、候选列表、工作台内容、计划书 |
| `components/` | 工作台交互、候选详情、地图、时间轴、确认与辅助弹窗 |
| `styles/` | 基础、工作台与产品样式 |
| `app.js` | 页面事件绑定、启动协调 |

每个对外函数只有一个定义。需要组合展示时直接调用命名函数，不再保存旧函数、加载后覆写全局函数。新增功能应归入实际所属模块，同时更新 `index.html`；后端按相对资源路径计算版本，页面刷新时加载对应文件。

共享状态暂保留在 `core/state.js`，不是完整组件框架。此次整理集中于明确职责、移除覆盖链和保持现有交互；改用 Vue 或 ES 模块需要独立迁移，不属于本轮工作。

当前隔离验证入口见 [脚本导航](../scripts/README.md)。
