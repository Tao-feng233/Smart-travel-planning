# 页面恢复、交通与数据覆盖修复

日期：2026-10-09
整合分支：feat/shitu-v11-review-integration

## 页面报错、计划页与刷新登录

车站与酒店的接驳事件没有备选路线字段，计划书页面直接调用 options.map 导致渲染中断。导航状态已改变，但旧页面未替换；刷新恢复旅行时，同一异常又被当作服务连接失败，带回登录入口。现在新接驳事件补齐结构，页面兼容旧记录与可选列表。登录恢复单独检查身份，只在401时显示登录；服务不可用时显示连接重试，无需重新输入密码。已保存凭据仍使用原来的HttpOnly Cookie，没有改到本地明文存储。

## 交通安排

时间轴交通条目只显示出发/抵达时刻、交通方式、预计耗时和额外缓冲，起终点保留在点击详情与计划书中。

计划书与Markdown导出展示地图接口返回的打车预估、道路收费、公交地铁票价、线路及上下车站。单段多个buslines是备选线路，不能全排成连续换乘。接口没有价格或线路时明确待核实；打车预估不是实时叫车报价，自驾费用不能用出租车预估替代。

往返交通为可选：交通页可选择“自驾游”或“往返自行安排”，也可在旅行信息设置。显式改为自行安排会取消旧的往返班次选择，保留景点、住宿和餐厅，要求重排旧计划；自驾优先采用驾车路程。该设置不等于已知跨城到达/离开时刻，首尾日依旧保留弹性及待核实说明。选择真实车票后恢复按班次核对。

## 推荐前的位置核对

途牛酒店资料与高德地点不同源，名称别名、分店歧义、空字段或接口超时都会导致无法安全匹配。新推荐先核对有效坐标：酒店保留名称/地址一致性检查，缺坐标高德POI通过原ID补查详情。未定位或匹配歧义候选不进入发布列表，不虚构位置。位置有效而道路查询超时仍标为道路待核实，不混淆成地点不存在。原有用户选择保留，可重新核对或更换。

## 数据覆盖

旧目的地页19城市来自已保存目录，10页是每页2城市的有限分页，并没有翻页生成城市。现在改为首批4个方向和其他已入库地区的展开列表，不再使用连续页码。

覆盖检查读取已有目的地目录及知识资料。没有记录的城市（如洛阳）在更改旅行条件之前提示“数据库暂时缺失数据，请选择其他地区”，不清空已有选择。用户明确点名但未入库的景点同样被拦截；地图返回的地点仅用于补充已有记录的坐标/运营资料，不自动扩大景点推荐范围。此批保留19城市，没有新增采集数据。目录中的代表景点介绍属于已有数据，但不代表票价、开放与预约等详细事实已完整。
