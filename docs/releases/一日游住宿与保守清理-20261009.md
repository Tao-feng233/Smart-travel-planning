# 一日游住宿与保守清理

日期：2026-10-09
分支：feat/shitu-v11-review-integration

## 住宿修复

住宿查询入口曾直接拒绝游玩天数为1的请求，导致一天游玩、当晚住下、第二天离开的合理行程无法查询酒店。已删除此限制，继续使用现有的逐晚住宿日期计算。

- 一天游玩且尚未指定返程日期时，可查询游玩当天入住、次日退房的酒店。
- 明确次日返程也可以查询并选定当晚住宿，房型仍为可选项。
- 仍按用户明确返程日期或已确认班次计算实际住宿晚数，不修改用户车票，不自动添加超出实际返程日期的住宿。
- 景点完成后的提示同时说明住宿可以查询或跳过；模型提示也明确游玩天数不限制住宿查询。

`source-and-config.zip`保存当前源码和本地配置，`travel.db`通过SQLite一致性备份保存，完整性检查结果为ok，`manifest.json`记录文件校验值。此目录已被Git忽略，配置及数据库不上传。
