# 山东景区资料覆盖说明

采集日期：2026年10月8日。此次按适量补充原则完成首批资料，不继续扩大采集规模。

## 覆盖范围

新增52条来源明确的资料记录，覆盖山东16个地市。其中23条来自文化和旅游部公开目录（16条景区、7条旅游度假区），29条来自地方政府、景区公共机构及山东地方志等页面。记录数不等于独立景点数，同一景点可能有介绍与运营说明两条记录，一篇线路资料也可能涉及多个景点。

目的地目录新增15个城市，保留原有青岛资料及成都、杭州、西安，共19个目的地。新城市的代表景点名称均可追溯到已采集正文，供高德查询和模型比较使用；不会生成虚构POI或坐标。

## 来源与数据边界

- 主要入口：[文化和旅游部山东公开目录](https://lyfw.mct.gov.cn/site/special/province?pkey=shandong&type=0)。其静态页面数据仅解析字面量，不执行脚本；天气和未标明坐标系的坐标不入库。
- 50条为景区特色或历史背景；2条为运营资料快照，分别为济南天下第一泉问答（2026-09-20）和刘公岛票务说明（2026-04-20）。快照不保证出游日仍然适用，也不代表库存或已预订。
- 2022年等历史线路保留原发布时间和背景用途，已去除此次采集中的特色美食及历史公交段落；地方志仅截取相关景观介绍，不保留无关经济统计。
- 德州齐河黄河国际生态城目录缺少详细介绍，明确记录该缺失，不补造内容。
- 4个计划补充的页面未采集成功：那香海、青岛北九水、青岛二龙山、日照万平口。未将这些页面列为成功数据；网络异常或规则无法确认时保留后续重试入口。山东旅游网站整站禁止自动采集，未进行批量抓取。
- 抓取仅使用审核过的公开来源和跳转域名，检查robots规则、控制访问间隔、使用系统证书验证，不访问登录后资料。收集失败保留已有有效版本。

## 使用与更新

来源注册表：`data/knowledge-sources-shandong.json`；正文：`data/knowledge/shandong.json`；目的地推荐目录：`data/catalog/shandong-destinations.json`。

```powershell
.\.venv\Scripts\python.exe scripts/collect_knowledge.py --registry data/knowledge-sources-shandong.json --output data/knowledge/shandong.json
.\.venv\Scripts\python.exe scripts/build_knowledge_index.py
.\.venv\Scripts\python.exe scripts/check_data_service.py --shandong
```

采集只刷新已有注册来源，不自动扩展网站或增加城市。正文更新后需重建索引；目的地摘要和代表景点为人工核对后的目录，不随页面变化自动改写。失败明细写入忽略的`data/runtime/shandong-collection-report.json`，采集命令遇到部分失败会返回非零状态，但成功资料仍可原子发布。

RAG按城市及经过核对的县市别名过滤；例如“曲阜市”可检索济宁三孔的相关记录，但不会自动放开济宁所有其他景点。地图、道路与真实地点仍从高德查询；文化和旅游部的未核对坐标不会替代GCJ-02坐标。

## 验证结果

181项后端回归通过；真实stdio MCP、中文Embedding与Qdrant验证通过，新增济南、泰安、曲阜、滨州、日照、威海6组检索场景，同时复核旧城市检索和日期隔离。

全量知识库现有90条记录，经父子切分生成78个父块、181个子块；上述数量包含原有其他城市资料，不代表新增90个山东景点。
