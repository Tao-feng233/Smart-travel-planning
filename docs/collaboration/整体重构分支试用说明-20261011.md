# 整体重构分支试用说明

本轮试用分支：`feat/shitu-refactor-20261011`。请切换整个分支，后端与前端目录都已整理，不要只复制某几个旧文件。原整合分支和主分支继续保留。

## 拉取与启动

先保存自己的未提交改动，再从仓库目录运行：

```bash
git fetch origin
git switch --track origin/feat/shitu-refactor-20261011
```

如果已创建过同名本地分支，改用 `git switch feat/shitu-refactor-20261011`，然后 `git pull --ff-only`。

切换后先在旧启动窗口按 Ctrl+C 停止旧服务，再运行 `python scripts/start.py` 或原 `启动.cmd`。仅刷新页面不会加载新的后端代码；启动器发现同一路径的旧服务仍健康时会直接复用它。

使用自己的根目录 `.env`；沿用现有虚拟环境，依赖不变。首次安装按根目录 README 完成依赖安装及知识索引初始化。新服务启动后，页面已打开时按 Ctrl+F5 刷新。

公开的知识原文、采集来源、地区目录和检索代码均在分支里。本机模型缓存、Qdrant 索引、密钥、账户与旅行数据库不随分支上传；首次环境需按 README 初始化索引，已有有效模型缓存可复用。

## 建议重点试用

1. “车票我自己安排，其他帮我选好”：检查能否查询、代选并继续生成，而不是强制手选。
2. 一天游玩、住一晚、次日离开：游玩天数仍为一天，住宿位置可选，房型可留空。
3. 修改、替换、取消和撤销选择：检查原旅行与其他夜晚、餐次是否保留。
4. 调整时间轴：检查道路耗时、午休、闭馆、指定时段、景区内午餐以及不必要折返。
5. 刷新页面、切换旅行、进入计划页面：检查登录恢复、地图隔离和旧计划展示。

代码验证：506项后端检查、8组页面回归、12组生成器重构前后差分通过。模型最终抽测11/12，仍可能把交通查询理解为整体检查；反馈时请附本轮消息、处理过程和实际结果。
