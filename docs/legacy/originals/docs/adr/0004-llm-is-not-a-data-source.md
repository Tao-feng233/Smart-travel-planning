# LLM不是旅游事实来源

LLM只负责理解用户、比较候选、提出决策和生成解释；目的地、开放时间、价格、路线、住宿、餐饮和天气等信息必须来自项目自身的数据层、RAG证据或MCP工具。系统只把知识库检索到的候选ID和证据交给LLM，并在输出后进行ID、证据和约束校验；资料不足时停止生成已验证攻略，不允许模型用预训练记忆补全。
