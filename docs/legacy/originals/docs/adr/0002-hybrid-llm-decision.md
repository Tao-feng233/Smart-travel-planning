# 使用受约束的LLM决策而不是纯打分或纯生成

目的地和地点选择先由程序排除违反支持范围、日期、预算和可用性的候选，再由RAG提供证据、LLM进行主观比较和天数建议，最后由程序验证结果。该方案保留LLM处理模糊需求和非固定表达的价值，同时避免模型把记忆当事实或推荐数据库外实体。
