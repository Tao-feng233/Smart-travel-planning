# 使用MySQL和Chroma分离事实与认知知识

项目使用MySQL保存开放时间、价格、坐标、用户状态和行程等结构化事实，使用Chroma保存认知卡片和攻略摘要等向量知识，并通过实体ID关联。这样既保留团队选择MySQL的低门槛，也能明确展示RAG能力；代价是需要一个小型索引构建脚本，但试点数据量下可以直接重建索引，无需复杂实时同步。
