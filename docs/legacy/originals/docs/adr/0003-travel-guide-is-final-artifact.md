# 以定制可执行旅游攻略作为最终产物

项目的用户侧最终产物统一定义为 `TravelGuide`，而不是目的地建议、景点列表或仅包含时间轴的 `ItineraryPlan`。`ItineraryPlan`继续作为内部规划核心，经过验证后与抵达方式、行前准备、住宿、预算、备用方案和数据来源共同组装为可版本化、可更新的攻略；这样所有LLM、RAG、MCP和重规划能力都围绕同一用户结果收敛。
